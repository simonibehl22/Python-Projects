# Test Driven Development Projects

All these python files are test driven development projects. Each has a different goal to achieve, but using various tests to ensure accuracy and account for edge cases.

calendars.py - using TDD to determine if years in different calendar types, Gregorian and Milkanovik, are leap years as well as well as other details.

playfair.py - uses TDD to take an input string and creates a playfair table to encrypt the message.

rational.py - uses TDD to implement rational numbers accurately and precisely.

reductions.py - uses TDD to check if words are in a word list.
